🔢 Math Operations

Use ** for powers (e.g., x**2), * for multiplication (e.g., 3*x)

Input Syntax Guide:

  • x**2 for x²
  • sin(x), cos(x), tan(x) for trigonometric functions
  • exp(x) for e^x
  • log(x) for natural log
  • sqrt(x) for square root
For Best Results:
  • Keep expressions simple: sin(x)*log(x) is good, avoid very long expressions
  • Test complex terms separately
  • Break down complex problems into simpler steps
Keep Expressions Simple:
  • Break complex expressions like sin(x)*log(x)-x^9 into smaller parts
  • Avoid nested functions like sin(cos(log(x))) when possible
  • Test complex terms separately before combining them
  • Use simpler alternatives where possible (e.g., x^2 instead of exp(2*log(x)))
Use dy/dx for first derivative, ** for powers

Differential Equation Format:

  • Correct: dy/dx = x**2 - x**5
  • Correct: dy/dx + 3*y = sin(x)
  • Incorrect: dy/dx = x**2 - x**5 = 0 (too many equals signs)
  • Incorrect: x**2 - x**5 (missing dy/dx and equals sign)
Performance Tips:
  • Start with simpler equations: Try dy/dx = x**2 before dy/dx = exp(-x)*sin(x)*tan(x)

Constants will be automatically generated when plotting.

Differential Equation Syntax:

  • Use d²y/dx² for second derivative
  • Always include = in your equation
Use ** for powers (e.g., x**2), * for multiplication
Tips for Complex Integrals:
  • For complex expressions like sin(x)*log(x)-x^9, use definite integrals with specific bounds
  • Expressions with nested functions may fall back to numerical integration
  • For better performance, split complex integrals into simpler terms

Integration Syntax:

  • Use x**2 for x² (not x^2)
  • Use sin(x), cos(x) for trigonometric functions
  • Use 1/x for fractions
  • Use sqrt(x) for square root
Enter only the expression to differentiate (NOT "dy/dx = ..." or "... = 0")

Derivative Input Guide:

  • Correct: x**2 - x**5 + sin(x)
  • Incorrect: dy/dx = x**2 - x**5
  • Incorrect: x**2 - x**5 = 0
