🔢 Math Operations

Use ** for powers (e.g., x**2), * for multiplication (e.g., 3*x)

Input Syntax Guide:

  • x**2 for x² (not x^2)
  • sin(x), cos(x), tan(x) for trigonometric functions
  • exp(x) for e^x
  • log(x) for natural logarithm
  • sqrt(x) for square root
Use dy/dx for first derivative, ** for powers

Constants will be automatically generated when plotting.

Differential Equation Syntax:

  • Use dy/dx for first derivative
  • Use d²y/dx² for second derivative
  • Always include = in your equation
  • Use standard functions: sin(x), exp(x), etc.
Use ** for powers (e.g., x**2), * for multiplication

Integration Syntax:

  • Use x**2 for x² (not x^2)
  • Use sin(x), cos(x) for trigonometric functions
  • Use 1/x for fractions
  • Use sqrt(x) for square root
Use ** for powers (e.g., x**3), * for multiplication

Derivative Syntax:

  • Use x**3 for x³ (not x^3)
  • Use sin(x), cos(x) for trigonometric functions
  • Use exp(x) for e^x
  • Use log(x) for natural logarithm
  • Order specifies the nth derivative (1st, 2nd, etc.)
